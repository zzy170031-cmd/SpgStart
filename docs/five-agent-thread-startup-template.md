## Recommended Usage Notes

- Use `Full Council` for new projects, major features, merge gates, and release gates.
- Use `Fast Gate` only when the thread has already passed earlier governance checkpoints.
- If all five agents do not start successfully, do not continue as if full governance is active.
- Keep the startup message at the top of the thread so later review can clearly see where governance began.
